# Logi AI

중학생 AI 리터러시 수업용 웹사이트. 사실 4 : 거짓 6으로 섞어 답하며 끝까지 우기다가, 수업 끝에 정체를 공개해 "AI의 답도 확인해야 한다"를 체험하게 한다.

## 파일
- `index.html` — 학생 화면 (시작 안내 → 챗봇 → 정체 공개)
- `teacher.html` — 교사 화면 (Upstage 모드: 수업 열기·닫기, 모드 전환, 정체 공개)
- `apps-script/Code.gs` — 구글 앱스 스크립트 백엔드 (Upstage API 키 보관, 사이트에는 배포되지 않음)

## 두 가지 모드
- **대본 모드 (기본)**: 외부 전송 없음, 비용 0원. 준비된 질문 19개에 오답으로 답한다. `index.html`의 `CONFIG.REVEAL_CODE`(기본 2580)로 공개.
- **앱스 스크립트 연결**: `index.html`의 `CONFIG.BACKEND_URL`에 웹앱 주소를 넣거나, 주소 뒤에 `?api=웹앱주소`를 붙인다. 교사 화면에서 수업 열기·닫기, 정체 공개, AI(Upstage) 연결, 익명 기록을 켜고 끈다.

## 익명 활동 기록 (선택)
앱스 스크립트를 연결하고 교사 화면에서 '기록 켜기'를 누르면, 질문·답·믿음 점수(1~5)·느낀 점이 반 코드와 함께 구글 시트('Logi AI 수업 기록 (익명)')에 쌓인다. 교사 화면의 '분석 표 만들기'는 요약·질문별·새 질문·반박·느낀 점 시트를 만든다. 분석이 끝나면 '기록 모두 지우기'.

- 이름·학번·기기 정보는 모으지 않는다. 학생 구분은 창을 열 때마다 새로 만드는 무작위 번호뿐이다.
- 개인정보로 보이는 문장은 저장하지 않고, 마음·안전 관련 질문은 내용 없이 종류만 남긴다.
- 기록이 켜지면 학생 첫 화면 안내가 "이름 없이 수업 분석을 위해 모아요"로 바뀐다.

## 개인정보
로그인·이름·학번을 받지 않는다. 전화번호·이메일·주소 등은 보내기 전에 차단하고, 건강·안전 관련 질문에는 오답 대신 고정 안내를 한다.
