# Logi AI

중학생 AI 리터러시 수업용 웹사이트. 일부러 그럴듯한 오답을 하고 끝까지 우기다가, 수업 끝에 정체를 공개해 "AI의 답도 확인해야 한다"를 체험하게 한다.

## 파일
- `index.html` — 학생 화면 (시작 안내 → 챗봇 → 정체 공개)
- `teacher.html` — 교사 화면 (Upstage 모드: 수업 열기·닫기, 모드 전환, 정체 공개)
- `apps-script/Code.gs` — 구글 앱스 스크립트 백엔드 (Upstage API 키 보관, 사이트에는 배포되지 않음)

## 두 가지 모드
- **대본 모드 (기본)**: 외부 전송 없음, 비용 0원. 준비된 질문 19개에 오답으로 답한다. `index.html`의 `CONFIG.REVEAL_CODE`(기본 2580)로 공개.
- **Upstage 모드**: `index.html`의 `CONFIG.BACKEND_URL`에 앱스 스크립트 웹앱 주소를 넣거나, 주소 뒤에 `?api=웹앱주소`를 붙인다.

## 개인정보
로그인·이름·학번을 받지 않고, 대화를 어디에도 저장하지 않는다. 전화번호·이메일·주소 등은 보내기 전에 차단하고, 건강·안전 관련 질문에는 오답 대신 고정 안내를 한다.
