내가 받은 답과 실제 사실

우리가 믿게 된 이유 — 모두 연출이었어요

  • 정확도 98.7%, 검증된 지식 120만 건 → 근거 없이 지어낸 숫자예요.
  • "○○대학교 연구" 같은 출처 → 실제로 없는 연구예요. 진짜 AI도 없는 논문을 만들어 낼 때가 있어요.
  • "👍 ○○명이 도움이 됐다고 했어요" → 무작위로 만든 숫자예요.
  • 타이핑 효과, "생각 중…" → 고민하는 척하는 화면 연출이에요.
  • 자신 있는 말투, 반박해도 우기기 → 확신이 강하다고 정확한 것은 아니에요.
  • 깔끔한 디자인, "✓ 검증된 답변" 표시 → 디자인은 내용의 정확성과 관계없어요.

오늘 기억할 것

  1. AI의 답은 그럴듯해도 틀릴 수 있어요.
  2. 중요한 내용은 교과서, 공식 사이트, 선생님께 다시 확인해요.
  3. AI가 내세우는 출처도 실제로 있는지 찾아봐요.
